# Brand to Product Polish

Use this skill when a project has brand references or visual studies that should
inform the product without overwhelming it.

## Workflow

1. Audit the source material.
   - Identify palette, typography, logo marks, icon style, and tone.
   - Detect domain-specific copy that belongs to another product.
   - Keep private or exploratory assets out of commits unless explicitly approved.

2. Extract tokens, not noise.
   - Convert useful colors into CSS variables or design tokens.
   - Reuse visual hierarchy, not irrelevant marketing text.
   - Keep brand artifacts ignored if they are private studies.

3. Apply by surface type.
   - Operating workbench: restrained, dense, signal-driven.
   - Pitch page: more expressive, visual, and narrative.
   - Paper artifact: quiet, evidence-first, no decorative claims.

4. Validate usability.
   - Color has semantic meaning.
   - Text remains readable.
   - Controls are still obvious.
   - Mobile has no overflow.
   - No logo or background competes with analytical content.

5. Document the decision.
   - State which brand ideas were adopted.
   - State which assets were not copied and why.
   - Keep the document short and product-facing.

## Rule of Thumb

Brand should increase trust and recall. If it slows repeated analytical work, it
belongs in the pitch site, not the product workbench.
