# ACM ICAIF Paper Scaffold

This directory contains a neutral ACM `sigconf` paper scaffold for ArenaWealth
Pro. It is a writing skeleton, not a finished submission.

Build locally if LaTeX is installed:

```bash
latexmk -pdf main.tex
```

The manuscript should not claim investment outperformance until the repository
contains reproducible backtests, baselines, ablations, and cost modeling.
