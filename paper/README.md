# Paper Scaffold

This directory contains a neutral `acmart` `sigconf` paper scaffold for
ArenaWealth Pro, in anonymous review mode. It is a writing skeleton, not a
finished submission, and names no venue, author, or institution.

Build locally if LaTeX is installed:

```bash
latexmk -pdf main.tex
```

The manuscript should not claim investment outperformance until the repository
contains reproducible backtests, baselines, ablations, and cost modeling.
