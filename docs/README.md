# Documentation

This directory contains maintained product and reviewer documentation.

Recommended reading order:

1. `../README.md` for setup and validation.
2. `reviewer/REVIEWER_GUIDE.md` for the reviewer quickstart.
3. `REPRODUCIBILITY_GUIDE.md` for validation details.
4. `guides/architecture.md` for system structure.
5. `guides/fundamental_analysis.md` and `guides/compounding.md` for scoring logic.
6. `PAPER_TARGET.md`, `PAPER_PATH.md`, and `COMMERCIALIZATION.md` for venue,
   research, and product limits.

Files archived under `archive/` are historical work products and are not part of
the supported artifact.
