# Documentation

This directory contains maintained product and reviewer documentation.

Recommended reading order:

1. `../README.md` for setup and validation.
2. `REPRODUCIBILITY_GUIDE.md` for reviewer execution steps.
3. `guides/architecture.md` for system structure.
4. `guides/fundamental_analysis.md` and `guides/compounding.md` for scoring logic.
5. `PAPER_PATH.md` and `COMMERCIALIZATION.md` for research and product limits.

Files archived under `archive/` are historical work products and are not part of
the supported artifact.
