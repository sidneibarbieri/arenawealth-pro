# Documentation

This directory contains maintained product and reviewer documentation.

Recommended reading order:

1. `../README.md` for setup and validation.
2. `reviewer/REVIEWER_GUIDE.md` for the reviewer quickstart.
3. `REPRODUCIBILITY_GUIDE.md` for validation details.
4. `PRODUCT_STRATEGY.md` for product modes and reviewer stories.
5. `AI_FINANCE_SOTA.md` for the state-of-the-art map and research direction.
6. `SCIENTIFIC_LEDGER.md` for findings, negative results, and open hypotheses.
7. `RESEARCH_PROCESS.md` for how observations become supported paper claims.
8. `ADVISOR_LLM_PROVIDERS.md` for provider setup and model-run evidence rules.
9. `guides/architecture.md` for system structure.
10. `guides/fundamental_analysis.md` and `guides/compounding.md` for scoring logic.

Private strategy notes, pitch packets, and reusable local assistant skills are
kept outside the publishable artifact. Files archived under `archive/` are
historical work products and are not part of the supported artifact.
